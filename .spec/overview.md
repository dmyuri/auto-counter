# Visão

## O que é
MVP para contagem e classificação automática de veículos utilizando visão computacional. O sistema acessará diretamente URLs públicas dos vídeos das cämeras de trânsito disponibilizadas pela NitTrans e fará o processamento de contagem dos veículos.

## Para quem
- Projeto de extensão sobre mobilidade urbana de Niterói:
    - Docente: responsável por supervisionar o projeto e utilizar os dados gerados nas análises.
    - Integrante: responsável por executar as análises, selecionar câmeras e períodos e consultar os resultados.
- Banca do meu TCC

## O que NÃO é
- Não é um sistema para suportar multiplos usuários simultaneos
- Não é um sistema para processamento massivo
- Não é um sistema de execução automática ou agendada.
- Não é um sistema de monitoramento contínuo das câmeras. 
- Não prevê o fluxo futuro de veículos.

## Restrições
- Deve rodar localmente em computadores fracos
- Não deve exigir servidor dedicado
